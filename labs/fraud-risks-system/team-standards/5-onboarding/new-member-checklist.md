# New Member Checklist

[← Back to Standards](../README.md)

---

### Week 1
- [ ] Access provisioned (GitHub, Jira, Slack, cloud console)
- [ ] Local dev environment running
- [ ] Shadow a PR review
- [ ] 1-on-1 with lead scheduled

### Week 2
- [ ] First ticket assigned (starter issue)
- [ ] Architecture walkthrough session
- [ ] Paired programming session with a peer
- [ ] Team standards doc read & acknowledged

### Week 4
- [ ] Independently close 2 tickets
- [ ] Lead first code review
- [ ] 30-day feedback sync with lead
