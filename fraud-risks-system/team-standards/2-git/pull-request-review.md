# Pull Request & Code Review

[← Back to Standards](../README.md)

---

- PR must link to a ticket.
- PR description: **What / Why / How to test**.
- Minimum **1 approval** for `develop`; **2 approvals** for `main`.
- Author responds to review comments within **1 business day**.
- Reviewer completes review within **1 business day**.
- No self-merge except hotfixes (lead approval required).
